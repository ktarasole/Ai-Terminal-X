# AI Terminal X - Русская версия

Расширение для поддержки русского языка в AI Terminal X.

## Возможности

- Распознавание команд на русском языке
- Автоматическое преобразование русских команд в терминальные
- Поддержка как русских, так и английских команд
- Интеллектуальная обработка естественного языка

## Установка

1. Клонируйте репозиторий:

git clone https://github.com/ktarasole/Ai-Terminal-X/

cd Ai-Terminal-X

2. Установите зависимости:

pip install -r requirements.txt

3. Настройте API ключ в файле .env

4. Запустите программу:

python main.py


**Примеры русских команд:**

✅ **список файлов** - показывает содержимое текущей папки

✅ **создать папку проект** - создает папку "проект"

✅ **показать процессы** - показывает запущенные процессы

✅ **текущая папка** - показывает текущую рабочую директорию

✅ **очистить экран** - очищает терминал


**Программа понимает множество русских команд для:**

🔹 Работы с файлами и папками

🔹 Управления процессами

🔹 Сетевых операций

🔹 Системного мониторинга

# Настройка русских моделей

## Вариант 1: Yandex GPT (рекомендуется)
1. Зарегистрируйтесь в Yandex Cloud
2. Создайте API ключ в разделе IAM
3. Получите Folder ID в настройках облака
4. Установите переменные в .env файле

## Вариант 2: Локальные модели (бесплатно)
1. Установите PyTorch: `pip install torch`
2. Модель скачается автоматически при первом запуске
3. Требуется минимум 4GB оперативной памяти

## Преимущества русских моделей:
- Лучшее понимание контекста на русском
- Нет ограничений API
- Работа оффлайн (локальные модели)
- Бесплатно (локальные модели)
